✨ AI 整理重點（對話逐字稿）

填寫報告書時，把這次的對話紀錄貼到「對話逐字稿」欄位，按「AI 整理重點」就會自動幫妳整理出一版「諮詢重點與建議」跟「注意事項」草稿，記得確認內容後再儲存。

這個功能需要先設定好 AI 金鑰才能使用：打開 Apps Script 編輯器 → 左側「專案設定」→「指令碼屬性」→ 新增一筆屬性，名稱填 ANTHROPIC_API_KEY，值貼上妳的 Claude API 金鑰 → 儲存。金鑰只會存在 Apps Script 後台，不會出現在網站或GitHub上，比較安全。設定好之後不用重新部署，直接就能用。
